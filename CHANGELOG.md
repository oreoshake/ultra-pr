# Changelog

## 0.3.0 — 2026-11-10

- Closing either side of a split closes the other. If you separate the split first, the tabs are left alone.

## 0.2.0 — 2026-11-10

- Follow a link to another pull request in either side of a split and the other side switches to that pull request's other view.
- Follow a link anywhere else (including a pull request's Commits or Checks tabs) and the other side closes.

## 0.1.0 — 2026-11-05

- Opening a pull request's Conversation opens its Files changed alongside in split view, and the reverse.
- Each tab is paired once per pull request, so a split you separate isn't reopened.
